# 山河访古 · 攻略库

历史文旅攻略合集：根据历史读书笔记生成的可实地行走攻略，虚实对照、以地证史。

## 目录

- `index.json` — 全部攻略的元数据索引（主题 / 覆盖地 / 关键词 / 文件名），供技能运行时动态获取
- 各 `.md` 文件 — 攻略正文，文件头部含自描述元数据

## 攻略清单

| 主题 | 覆盖地 |
|---|---|
| 晋国从一隅之地到百年霸权 | 曲沃 / 运城 / 太原 |
| 楚国七十年迁徙与南方崛起 | 淅川 / 荆州 |
| 周天子为何守着富庶之地却无法复兴 | 洛阳 |

## 使用方式

「山河访古攻略库」技能会优先读取 `index.json`（经 jsDelivr CDN），按覆盖地或关键词匹配攻略后返回正文；离线时回退到技能内置的少量攻略。

## 新增攻略

新攻略加入时：在文件头部写好元数据头（主题/覆盖地/关键词），放入本目录并更新 `index.json` 即可，技能无需重新发布。
